name: setting-up-doriath-profiles
description: Write a doriath profile for a project, with the person's approval for each file. Use when the person asks to set up doriath for a project, to write or change a doriath profile, or to run their agent in a doriath jail.
---

Run `doriath guide profile` and follow the steps that it prints. The guide comes from the installed doriath, so it matches its version.

If the command is not found, tell the person to install doriath: https://doriath.fnune.com/install/.
