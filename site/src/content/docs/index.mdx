## Motivation

I build doriath because I want to run coding agents on a remote server, without watching them all the time. An agent with access to my files, my keys and my logins is not safe to leave alone. It is not safe when I watch it either: I read fast, and one prompt injection in a web page or an issue is enough.

## Scope

doriath gives the agent only what its task needs, and holds the actions that matter until you answer. The agent sees the repository and the paths that the profile names. It reaches the hosts that the profile allows, and never reads the tokens that the proxy adds for it. Merges, releases, pushes and other hosts wait for you. Thus the profile decides what a session can do, as the [threat model](/threat-model/#profiles) describes.

The agent uses your toolchain on your kernel, so a session starts in under a second. A virtual machine isolates more. [Architecture](/architecture/) describes each part.
