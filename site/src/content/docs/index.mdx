## Scope

Agents in a doriath jail use your own toolchain and checkouts, on your kernel, so a session starts in under a second and builds the way your terminal does. A container or virtual machine with an image of its own isolates more, at the cost of that shared setup. Doriath guards against an agent that acts against your intent, for example after it reads a prompt injection in a web page or an issue.

## Boundaries

Inside the jail, the repository you started in is read-only, and the agent commits in worktrees of its own. Your home directory, SSH keys and other projects are absent. Loopback is the only network: doriath's proxy, outside the jail, forwards a request when the profile allows its host, and adds tokens on the way for the programs that may use them, so `gh` can push while the agent never reads the token. Merges, releases, pushes and unknown hosts wait for your answer, which nothing in the jail can give.

## A first session

A profile lists the [modules](/reference/modules/) a kind of work needs, plus any hosts and [secrets](/reference/configuration/#secrets) of its own:

```toml title="~/.config/doriath/profiles/my-app.toml"
description = "My app: Go API and React frontend"
modules = ["base", "vcs", "docs", "go", "node", "github", "claude"]

[egress]
allow = ["api.stripe.com"]

[secrets.github]
command = ["rbw", "get", "github-my-app"]
```

Start the agent from the repository:

```sh
cd ~/Development/my-app
doriath run --profile my-app -- claude
```
