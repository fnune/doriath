## Install doriath

```sh
nix profile install github:fnune/doriath
doriath doctor
```

`doriath doctor` checks for what doriath needs: Linux with unprivileged user namespaces. bubblewrap comes bundled in the static binary. For the `podman` module you also need podman, util-linux `unshare` and `nsenter`, and subordinate ids for your user:

```sh
grep $USER /etc/subuid /etc/subgid
```

With home-manager, see [profiles with home-manager](/guides/home-manager/) instead.

## Create credentials for the agent

Give the agent credentials of its own. doriath adds them to requests outside the jail, so the agent never reads them.

For GitHub, create a [fine-grained token](https://github.com/settings/personal-access-tokens/new) for the repositories the agent works on, with an expiry, and read and write on Contents, Pull requests, Actions and Commit statuses.

Signing needs an SSH key of the agent's own, added to GitHub as a signing key. The commits it signs stay authored by you and show as verified:

```sh
install -d -m 700 ~/.config/doriath/keys
ssh-keygen -t ed25519 -N '' -C 'doriath agent signing' -f ~/.config/doriath/keys/agent-signing
cat ~/.config/doriath/keys/agent-signing.pub
```

## Write a profile

A profile says what one kind of work can reach. Save this as `~/.config/doriath/profiles/my-app.toml`:

```toml title="~/.config/doriath/profiles/my-app.toml"
description = "My app"
modules = ["base", "vcs", "docs", "go", "node", "github", "claude"]

# A file (mode 600) or a command such as rbw, sops or secret-tool.
[secrets.github]
command = ["rbw", "get", "github-my-app"]

[secrets.agent-signing]
file = "~/.config/doriath/keys/agent-signing"

[signing]
key = "agent-signing"
```

Each `[secrets.NAME]` table says where one secret comes from, and the name is how the rest of the configuration refers to it. `github` is the name the `github` module asks for: its `[[http]]` entries carry `credential = { secret = "github", ... }`, so the proxy adds that token to requests from `gh` and `git`. `agent-signing` is a name of your own choosing, used only because `[signing] key` names it; call it anything, as long as both match. doriath reads each one on the host once per session, and none of them enters the jail.

`doriath profiles show my-app` checks it. The repository you start in is read-only in the jail, and by default the agent commits in worktrees under `.claude/worktrees`. To keep them where yours are, such as `~/Development/.worktrees/my-app`, add that directory with `mode = "write"`:

```toml
[[mounts]]
path = "~/Development/.worktrees/my-app"
mode = "write"
```

A first build usually needs hosts the modules do not name. In learning mode every public host is reachable for one session, and doriath prints the `[egress]` lines to add once it ends:

```sh
doriath run --profile my-app --learn -- make build
```

<Aside type="caution">
  Learning mode reaches every public host. Keep it for builds you start
  yourself, and never give it to an agent.
</Aside>

## Run an agent

```sh
cd ~/Development/my-app
doriath run --profile my-app -- claude
```

Held requests show as desktop notifications. Without a desktop, `doriath approvals web --open` opens a page in your browser, and `doriath approvals watch` asks in another terminal; [answering requests](/guides/approvals/) has the details.

A plain `claude` still runs outside the jail. An alias such as `alias claude-app='doriath run --profile my-app -- claude'` works, and so does a line in the project's `.envrc`, described in [projects with direnv](/guides/direnv/).
