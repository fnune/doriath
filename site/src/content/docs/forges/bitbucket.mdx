---
title: Bitbucket
description: Use the bitbucket module with a repository access token for each profile.
---

The [`bitbucket` module](/reference/modules/#bitbucket) gives `git` your token on `bitbucket.org`, and `curl` your token on `api.bitbucket.org`. Other programs reach these hosts without it.

## Token

Create a repository access token or a workspace access token, with write access to repositories and pull requests, and add it to the profile:

```toml
[secrets.bitbucket]
command = ["rbw", "get", "bitbucket-my-app"]
```

## What waits for you

Merges of pull requests, pushes and the API requests that the module does not name wait for your answer. Reads, pull requests, comments and approvals of pull requests go through. Changes to webhooks, Pipelines variables and deploy keys are refused.
