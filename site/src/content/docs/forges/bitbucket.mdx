title: Bitbucket

The [`bitbucket` module](/reference/modules/#bitbucket) gives your token to `git` on `bitbucket.org`, and to `curl` on `api.bitbucket.org`.

## Token

Create a repository access token or a workspace access token, with write access to repositories and pull requests. Then add it to the profile:

```toml
[secrets.bitbucket]
command = ["rbw", "get", "bitbucket-my-app"]
```

## Requests

- Go through: reads, pull requests, and comments on and approvals of pull requests.
- Wait for your answer: merges of pull requests, pushes, and the API requests that the module does not name.
- Refused: changes to webhooks, Pipelines variables and deploy keys.

Branch rules, such as no force push to `main`, belong in the branch restrictions of the repository.
