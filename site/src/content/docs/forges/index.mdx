---
title: Forges
description: How a forge module gives the agent git and the forge's API with a token it never sees.
---

A forge hosts git repositories, such as GitHub, GitLab, Forgejo or Bitbucket. doriath has a [module](/reference/modules/) for each of these forges. In the profile, list the module of each forge that the agent uses.

A forge module holds the hosts of the forge, the credential that the proxy adds, and the request rules. It also tells the proxy how the forge names a repository, so that an allow for the session covers one repository.

## Tokens

Each forge module needs a secret with the name of the module, such as `[secrets.gitlab]`. Make a token for each profile, as [install](/install/#create-credentials-for-the-profile) describes. Give it access only to the repositories of that profile.

The proxy adds the token only for the programs of the module, such as `git` and the client of the forge.

## Requests

Reads and routine work go through. Approvals of pull requests, merges, releases, pushes and other writes wait for [your answer](/guides/approvals/). doriath refuses changes to webhooks, CI secrets and deploy keys. Each forge page lists its rules.

doriath holds each push for your approval. Set branch rules, such as no force push to `main`, in the branch protection of the repository.

## git over SSH

The jail has no route for SSH. In the jail, a forge module changes the SSH remotes of the forge, such as `git@gitlab.com:group/project.git`, into HTTPS remotes. Thus git goes through the proxy. Your git configuration outside the jail does not change. If the forge serves SSH on another host, such as `ssh.bitbucket.org`, the module names it under `ssh.hosts`. If git tries SSH to a host that no module of the profile names, doriath stops it with an error that names the host, and you push from outside the jail or add the forge's module.

## Git LFS

Each forge module gives the token to `git-lfs` too. Downloads go through. An upload waits for your answer at the batch request, where `git-lfs` names the objects that it sends. The push of the commits that name these objects waits as well.

## Self-hosted forges

A module names the hosts of the public service, such as `gitlab.com` or `codeberg.org`. For your own instance, copy the module to a new name:

```sh
doriath modules show gitlab > ~/.config/doriath/modules/gitlab-acme.toml
```

In the copy, change `host = "gitlab.com"` to the host of your instance. Then list `gitlab-acme` in the profile. If the instance does not use port 443, add the port to the host, such as `git.acme.example:8443`.
