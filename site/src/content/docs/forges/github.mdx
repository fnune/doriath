---
title: GitHub
description: Use the github module with a fine-grained token and a signing key for each profile.
---

The [`github` module](/reference/modules/#github) gives your token to `git`, `git-lfs` and `gh` on `github.com`, `api.github.com` and `uploads.github.com`.

## Token

Create a [fine-grained token](https://github.com/settings/personal-access-tokens/new) for the repositories of the profile only. Give it an expiry, and read and write access to Contents, Pull requests, Actions and Commit statuses. Then add it to the profile:

```toml
[secrets.github]
command = ["rbw", "get", "github-my-app"]
```

`gh` needs a token to start. The module gives it a placeholder, and the proxy replaces the placeholder with your token on each request.

## Commit signing

Create an SSH key for the profile, and add it to GitHub as a signing key. GitHub then shows the commits of the agent as verified, with you as the author. [Install](/install/#create-credentials-for-the-profile) shows the commands.

## Requests

- Go through: reads, pull requests, issues, comments and reruns of CI.
- Wait for your answer: merges, releases, pushes, Git LFS uploads, and the API requests that the module does not name.
- Refused: changes to webhooks, Actions, Dependabot and Codespaces secrets, collaborators and deploy keys. Changes to the webhooks and Actions secrets of organizations, and to the SSH, GPG and signing keys of the user, are refused too.

Branch rules, such as no force push to `main`, belong in the branch protection rules or rulesets of the repository.
