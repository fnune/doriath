The [`forgejo` module](/reference/modules/#forgejo) gives your token to `git` and to the clients `tea`, `fj` and `berg` on `codeberg.org`. Forgejo and Gitea serve git and the API on one host. For a different instance, copy the module and change the host, as [self-hosted forges](/forges/#self-hosted-forges) describes.

## Token

Create an access token in the settings of your account, with read and write access to repositories and issues. Then add it to the profile:

```toml
[secrets.forgejo]
command = ["rbw", "get", "codeberg-my-app"]
```

## Requests

- Go through: reads, pull requests, reviews, issues and comments.
- Wait for your answer: merges of pull requests, releases, tags, changes to files through the API, pushes, and the API requests that the module does not name.
- Refused: changes to webhooks, Actions secrets and variables, collaborators and deploy keys.

Branch rules, such as no force push to `main`, belong in the branch protection of the repository.
