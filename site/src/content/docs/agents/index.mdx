---
title: Agents
description: How doriath supports a coding agent, with and without an adapter.
---

doriath runs any command in a jail, so it can run any coding agent. A module says what the agent needs. An adapter is code in doriath for one agent.

## Modules

To use an agent, list its module in the profile, such as the [`claude` module](/reference/modules/#claude). The module mounts the config of the agent, gives it a state folder for each profile, and allows the hosts of its provider.

If an agent has no built-in module, write one in `~/.config/doriath/modules/`. Put the state folder of the agent under `[[caches]]`, so that each profile gets its own copy. Put the config files that the agent only reads under `[[mounts]]`. Allow the hosts that it calls.

## Adapters

Some things cannot be data. An adapter does them in code for one agent:

| What                       | With an adapter                                           | Without an adapter                                  |
| -------------------------- | --------------------------------------------------------- | --------------------------------------------------- |
| Permission prompts         | Go to the [approval queue](/guides/approvals/).           | Stay in the terminal of the agent.                  |
| Permission rules           | Are frozen for the session. The agent cannot loosen them. | Belong to the agent, and the agent can change them. |
| The session text           | Reaches the agent at the start of the session.            | The agent learns of the jail from the proxy errors. |
| MCP servers from `[[mcp]]` | Reach the agent in its own format.                        | Do not reach the agent.                             |
| Transcripts                | Come back to your own config when the session ends.       | Stay in the state folder of the profile.            |

doriath uses an adapter only if the profile lists the module of the agent. Without the module, doriath warns you and runs the command as it is. [Claude Code](/agents/claude-code/) has an adapter.

## Without an adapter

Add this line to the instructions of the agent: "When something is blocked, run `doriath status`." That command shows what the jail allows, what it blocked, and how to ask for a host or a path.
