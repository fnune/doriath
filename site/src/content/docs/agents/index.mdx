---
title: Agents
description: How doriath supports a coding agent, with and without an adapter.
---

doriath runs any command in a jail, so it can run any coding agent. A module says what the agent needs. An adapter is code in doriath for one agent.

## Modules

To use an agent, list its module in the profile, such as the [`claude` module](/reference/modules/#claude). The module mounts the config of the agent, gives it a state folder for each profile, and allows the hosts of its provider.

If an agent has no built-in module, write one in `~/.config/doriath/modules/`. Put the state folder of the agent under `[[caches]]`, so that each profile gets its own copy. Put the config files that the agent only reads under `[[mounts]]`. Allow the hosts that it calls.

## Adapters

Some things cannot be data. An adapter does them in code for one agent. Each agent page tells what its adapter does:

| What                       | [Claude Code](/agents/claude-code/) | [Codex](/agents/codex/) | [Gemini CLI](/agents/gemini-cli/) | [opencode](/agents/opencode/) |
| -------------------------- | ----------------------------------- | ----------------------- | --------------------------------- | ----------------------------- |
| Permission prompts         | Approval queue                      | Approval queue          | Terminal of the agent             | Terminal of the agent         |
| Permission rules           | Frozen for the session              | Frozen for the session  | The agent can change them         | The agent can change them     |
| Session text               | At session start                    | At session start        | In `GEMINI.md`                    | In its instructions           |
| MCP servers from `[[mcp]]` | Yes                                 | Yes                     | Yes                               | Yes                           |
| Transcripts                | Come back to your `~/.claude`       | Stay in the profile     | Stay in the profile               | Stay in the profile           |

The approval queue is the [approvals page and `doriath approvals`](/guides/approvals/). The session text tells the agent what the jail allows, what `doriath:` errors mean, and how to ask for a host or a path. The settings that each adapter shares are under [`[agent]`](/reference/configuration/#profile-keys) in the profile.

doriath uses an adapter only if the profile lists the module of the agent. Without the module, doriath warns you and runs the command as it is.

## Without an adapter

If your agent reads a global instructions file, name it under `instructions` in the module:

```toml
[agent]
instructions = ["~/.config/my-agent/AGENTS.md"]
```

In the jail, the file shows your instructions and then the session text, read-only. If you have no such file, the agent reads only the session text. The command `doriath status` shows the same text at any time.
