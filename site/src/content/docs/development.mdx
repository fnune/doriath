`nix develop` gives the toolchain: Go and its linters, the bubblewrap that the binary bundles, and Node for this site. These commands check, test and build doriath:

```sh
just check
just test-integration
just build
```

`just check` runs formatting, lint and the unit tests. The integration tests start real jails. They include a script for each way out of the jail that doriath closes. Write code as the [engineering principles](https://github.com/fnune/doriath/blob/main/docs/engineering.md) tell.

## This site

This site is a [Starlight](https://starlight.astro.build) project in `site/`. Its colors, fonts, ornaments and request cards come from `internal/ui`, as on the approvals page. The modules page reads `internal/modules` when the site builds. The build also writes `llms.txt`, and each page as Markdown at its path with `.md`, for agents. Each page links to its Markdown in its head and its footer. Write pages as `site/STYLE.md` tells. These commands serve and build the site:

```sh
just site-dev
just site-build
```

Each TOML code block must load as a profile, or as `config.toml` under a heading with that name. `TestDocExamplesLoad` reads all pages to check this.
