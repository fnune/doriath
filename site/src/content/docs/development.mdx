`nix develop` provides the toolchain, from Go and its linters to the bubblewrap the binary bundles and Node for this site.

```sh
just check
just test-integration
just build
```

`just check` covers formatting, lint and the unit tests. The integration tests start real jails, among them a script for every way out of the jail that doriath closes. How the code is written is up to the [engineering principles](https://github.com/fnune/doriath/blob/main/docs/engineering.md).

## This site

This site is a [Starlight](https://starlight.astro.build) project in `site/`. Its colors, fonts, ornaments and request cards come from `internal/ui`, which the approvals page uses too, and the modules page reads `internal/modules` at build time. `site/STYLE.md` sets how pages are written.

```sh
just site-dev
just site-build
```

Examples in TOML code blocks must load as profiles, or as `config.toml` under a heading of that name: `TestDocExamplesLoad` reads every page.
