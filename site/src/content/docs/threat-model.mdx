## Assumptions

Doriath assumes an agent that acts against your intent. A prompt injection in a web page, an issue or a dependency can cause that, and so can a plain mistake or a misread task. The agent is assumed capable: it runs any program the jail sees, writes any file it may write, and tries whatever the kernel allows.

## Guarded actions

| Attempt                                              | Guard                                                                                                                                                 |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Read your home directory, SSH keys or other projects | Not mounted. The jail sees the repository, the profile's paths and system paths.                                                                      |
| Read a token, or send it elsewhere                   | Tokens stay in the proxy, which adds them for the programs and hosts the profile names.                                                               |
| Reach a host the profile does not name               | Loopback is the jail's only network, and the proxy holds unknown hosts for you.                                                                       |
| Reach your local network or a cloud metadata service | The proxy refuses private, link-local and metadata addresses, whatever name resolves to them.                                                         |
| Merge, release or push without you                   | `[[http]]` rules hold those requests until you answer.                                                                                                |
| Approve its own requests                             | Answers come from your desktop, terminal or approvals page, all out of the jail's reach.                                                              |
| Change your checkout, or plant a git hook            | The checkout is read-only, and git's and jj's config, hooks and info stay read-only even in writable mounts.                                          |
| Rewrite or delete history                            | Existing packs are read-only, loose objects come back at the end, and `doriath restore` puts moved branches back.                                     |
| Escape through namespaces, `ptrace` or `bpf`         | seccomp refuses those calls, and Landlock limits writes.                                                                                              |
| Reach more through containers                        | A broker checks each podman API call: allowed images and the profile's mounts only, nothing privileged, and no host namespace other than the network. |

## Open paths

<Aside type="caution">
  Keep work an agent should not see out of its profile. Doriath limits what an
  agent reaches, and an allowed host can still receive whatever the agent reads.
</Aside>

Allowing writes allows exfiltration. A request to an allowed host with the agent's own API key is valid, and `gh` can post comments, so the mounted project can leave through any host the profile allows. Mount only the project, and allow only the hosts the task needs.

Programs the agent may use are programs it drives, with any arguments and through any config it can write. A credential that only `gh` gets is still used however the agent asks `gh` to use it; request rules and approvals decide what those calls may do.

The jail shares your user and your kernel, so a kernel or bubblewrap bug lets the agent out as you. Container sandboxes rest on the same kernel; a virtual machine adds a boundary doriath does not have.

Your answers are part of the boundary. Requests can carry text the agent wrote, which doriath labels as the agent's, and a long run of requests invites clicking allow. Once 32 are waiting, doriath refuses new ones.

[Security limits](/reference/security-limits/) lists every gap, each with the reason it stays.
