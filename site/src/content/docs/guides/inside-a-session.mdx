---
title: Looking inside a session
description: Run commands in a jail, reach its ports, and read what it did.
---

Servers the agent starts listen only inside the jail. Reach them from another terminal on the host:

```sh
doriath exec -- curl -sS http://localhost:3000
doriath exec
```

`doriath exec` runs a command, or a shell without one, as another process of the jail, with its files, network and limits.

```sh
doriath forward 3000
```

With `doriath forward`, port 3000 of the jail answers at `localhost:3000` on the host, for every local user of the machine. To debug a browser in the jail, start it with `--remote-debugging-port=9222`, forward 9222 and attach from `chrome://inspect`.

When several sessions run, pass `--session ID` from `doriath sessions`.

## Session history

```sh
doriath status
doriath log --since 1h
doriath log --denied --follow
```

`doriath status` lists what a session allows and what it blocked, with the profile lines that would allow it. The audit log at `~/.local/state/doriath/audit.jsonl` records every session, egress decision and approval, each with its session and profile, and `doriath log` reads it. For [lnav](https://lnav.org), the repository ships a format in `contrib/lnav`.

A session prints one summary line when it ends, followed by the hosts it learned as profile lines. Branches the agent moved go back with `doriath restore SESSION`.
