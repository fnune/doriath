---
title: Projects with direnv
description: Start your agent in the jail from anywhere in a project, alongside use flake.
---

[direnv](https://direnv.net) loads environment variables from a file named `.envrc` when you enter a folder, and unloads them when you leave. If you do not use direnv, skip this page. With the doriath library, one line in `.envrc` starts your agent in a session from anywhere in the project:

```sh title=".envrc"
use doriath my-app
```

`use doriath PROFILE` puts a script first on `PATH`, with the name of the command of your agent, such as `claude`. The script runs `doriath run --profile PROFILE --current ROOT -- COMMAND`, where `ROOT` is the folder of the `.envrc`. To wrap another command, add `--command NAME`. To [compose profiles](/reference/configuration/#composed-profiles), name each one, such as `use doriath my-app deploy`. To use a [repository profile](/reference/configuration/#repository-profiles), name it with `repo:`, such as `use doriath my-app repo:dev`. The script is in `~/.cache/doriath/shims/`, where no agent writes.

## Install the library

The [home-manager module](/guides/home-manager/#the-module) installs the library when direnv is on. Without home-manager, run:

```sh
doriath direnv > ~/.config/direnv/lib/doriath.sh
```

## With use flake

Put `use doriath` after `use flake` and other direnv functions, so that its script stays first on `PATH`:

```sh title=".envrc"
use flake
use doriath my-app
```

The jail sees the `PATH` that direnv builds and can read `/nix/store`, so the tools of the flake work in the jail. Other variables stay outside the jail, such as `AWS_PROFILE`. To pass a variable, list it in the profile:

```toml
[env]
pass = ["GOPRIVATE", "GOTOOLCHAIN"]
```

[Profile keys](/reference/configuration/#profile-keys) lists the other keys of `[env]`.

## A local .envrc

If the `.envrc` is in the repository, put the line in a file that the `.envrc` sources, such as `.envrc.local`. Keep that file out of the repository:

```sh title=".envrc.local"
use doriath my-app
```
