---
title: Projects with direnv
description: Start a plain claude in the jail for a whole project, alongside use flake.
---

With [direnv](https://direnv.net), one line in a project's `.envrc` makes a plain `claude` anywhere in the project start in a doriath session:

```sh title=".envrc"
use doriath my-app
```

`use doriath PROFILE` puts a small script named `claude` first on `PATH`, which runs `doriath run --profile PROFILE --current ROOT -- claude` with `ROOT` set to the folder of the `.envrc`. No agent writes to `~/.cache/doriath/shims/`, where the script lives. To wrap a command other than `claude`, add `--command NAME`.

The home-manager module installs the library when direnv is on. Without it:

```sh
doriath direnv > ~/.config/direnv/lib/doriath.sh
```

## With use flake

`use doriath` works with `use flake` and other direnv functions. Put it last, so that its script stays first on `PATH`:

```sh title=".envrc"
use flake
use doriath my-app
```

Since the jail sees the `PATH` that direnv builds and can read `/nix/store`, the flake's tools work inside it. Anything else the `.envrc` exports stays outside unless the profile passes it, which keeps cloud credentials such as `AWS_PROFILE` out of the jail. List further variables in the profile to pass them:

```toml
[env]
pass = ["GOPRIVATE", "GOTOOLCHAIN"]
```

## A local .envrc

When the project's `.envrc` is checked in, the line belongs in a file of your own that it sources, such as `.envrc.local`, kept out of the repository:

```sh title=".envrc.local"
use doriath my-app
```
