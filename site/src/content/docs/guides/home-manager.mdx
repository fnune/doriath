[home-manager](https://github.com/nix-community/home-manager) manages the programs and dotfiles of a user from a Nix configuration. The doriath module puts the binary, its integrations, the approvals page service and your profiles in that configuration. If you do not use Nix, skip this page and use the [release binary](/install/) with TOML profiles.

## The module

Add the flake as an input and import its module:

```nix title="flake.nix"
{
  inputs.doriath = {
    url = "github:fnune/doriath";
    inputs.nixpkgs.follows = "nixpkgs";
    inputs.home-manager.follows = "home-manager";
  };
}
```

```nix
{
  imports = [ inputs.doriath.homeManagerModules.default ];

  programs.doriath.enable = true;
}
```

| Option                  | Default                            | What it does                                                                                                                    |
| ----------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `enable`                | `false`                            | Installs doriath and writes `~/.config/doriath/config.toml`.                                                                    |
| `package`               | The flake's default package        | Selects the doriath package to install.                                                                                         |
| `direnv`                | `programs.direnv.enable`           | Installs the [direnv](/guides/direnv/) library, for `use doriath PROFILE`.                                                      |
| `zsh.completion`        | `programs.zsh.enable`              | Loads the zsh completion.                                                                                                       |
| `desktop.notifications` | `true`                             | Shows requests as [desktop notifications](/guides/approvals/#desktop-notifications).                                            |
| `desktop.web.enable`    | `true`                             | Runs the [approvals page](/guides/approvals/#the-approvals-page) as a systemd user service.                                     |
| `desktop.web.listen`    | `"127.0.0.1:7341"`                 | The loopback address of the page.                                                                                               |
| `desktop.tray`          | `desktop.web.enable`               | Shows the [tray icon](/guides/approvals/#the-tray-icon). The service then starts with the graphical session.                    |
| `approvals.host_wait`   | `null`                             | How long a host or path request waits. The default is `2m` with desktop notifications, otherwise `0s`, and the maximum is `1h`. |
| `approvals.tool_wait`   | `null`                             | How long a permission prompt waits. The default is `60s`, and the maximum is `1h`.                                              |
| `terminal.title`        | `true`                             | Names the session's profile in the terminal's window title.                                                                     |
| `terminal.bar`          | `true`                             | Shows the session on the terminal's last row, below the agent.                                                                  |
| `terminal.env`          | `{ }`                              | Sets variables on the process your terminal sees in place of the agent. `{command}` is the command's name.                      |
| `skill.enable`          | `false`                            | Installs the skill for [profiles with an agent](/guides/profile-setup/).                                                        |
| `skill.directories`     | `.claude/skills`, `.agents/skills` | The folders under the home directory where agents read skills.                                                                  |
| `profiles.<name>`       | `{ }`                              | Profiles, with the same keys as their TOML.                                                                                     |
| `modules.<name>`        | `{ }`                              | Your own modules. A module with the name of a built-in module is an error.                                                      |

The global options use the same names as the [config.toml keys](/reference/configuration/#configtoml-keys). For example, disable the terminal bar and allow 90 seconds for an agent permission prompt:

```nix
programs.doriath = {
  terminal.bar = false;
  approvals.tool_wait = "90s";
};
```

On a headless host, set `desktop.notifications = false` and `desktop.tray = false`. Set `approvals.host_wait` if requests must wait for an answer through the CLI or the [approvals page](/guides/approvals/#the-approvals-page).

## Profiles in Nix

A profile in Nix has the same keys as its TOML file, as attributes. It also has `packages`: tools that go first on the `PATH` of the jail, with no install on the host.

```nix
programs.doriath.profiles.my-app = {
  description = "My app";
  modules = [ "vcs-readwrite" "go" "github" "claude" ];
  secrets.github.command = [ "rbw" "get" "github-my-app" ];
  packages = [ pkgs.xvfb-run ];
  mounts = [
    {
      path = "~/Development/.worktrees/my-app";
      mode = "write";
    }
  ];
};
```

home-manager writes each profile to `~/.config/doriath/profiles/<name>.toml` as a link into the Nix store. `doriath profiles edit` refuses these files and tells you to edit the Nix configuration.

Profiles and modules accept all [profile keys](/reference/configuration/#profile-keys). A module names its secrets in `uses_secrets`, and a profile gives their sources.

Each [secret](/reference/configuration/#secrets) has one source: `file`, `command`, `keyring` or `oauth`, with `required` and `refresh` if needed. This example has a command that refreshes and both forms of [OAuth login](/reference/configuration/#oauth-logins):

```nix
programs.doriath.profiles.my-app.secrets = {
  api = {
    command = [ "team-token" ];
    refresh = "45m";
    required = true;
  };
  tools.oauth.mcp = "https://mcp.example.com/mcp";
  account.oauth = {
    issuer = "https://login.example.com";
    client_id = "doriath";
    scopes = [ "read" "write" ];
  };
};
```

## Profiles kept elsewhere

To keep some profiles as TOML files outside Nix, such as profiles that a team keeps in a repository, link their folder into `~/.config/doriath/profiles/`, as [configuration](/reference/configuration/) describes.
