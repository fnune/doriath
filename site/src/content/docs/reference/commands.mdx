title: Commands
description: Every doriath command, on the host and inside a jail.

You give the values of arguments in capitals. Arguments in brackets are optional. A command that works on one session takes `--session ID`, which you need only when more than one session runs.

## Sessions

### `doriath run`

```txt frame="none"
doriath run --profile NAME [--current DIR] [--learn] -- COMMAND
```

Runs a command in a jail for the profile. `NAME` can join several profiles with `+`, as [composed profiles](/reference/configuration/#composed-profiles) describes, such as `my-app+repo:dev` with a [repository profile](/reference/configuration/#repository-profiles). `--current DIR` sets the folder of the session, in place of the working folder. Before the first session of a profile, and when it gives more than you allowed, `run` asks you; see [allowed profiles](/reference/configuration/#allowed-profiles). `--learn` makes all public hosts reachable, and prints the hosts that the session used. See [install](/install/#find-the-hosts-of-a-build).

### `doriath exec`

```txt frame="none"
doriath exec [--session ID] [-- COMMAND]
```

Runs a command as a new process in a running jail. Without a command, it starts a shell. See [looking inside a session](/guides/inside-a-session/).

### `doriath forward`

```txt frame="none"
doriath forward [--session ID] PORT[:JAIL_PORT]
```

Makes a port of the jail reachable on the loopback address of the host.

### `doriath status`

```txt frame="none"
doriath status [--session ID]
```

Lists the running sessions. With one session, or with `--session`, it shows what the session allows and what it blocked. In the jail, the agent runs it to see its own session.

### `doriath log`

```txt frame="none"
doriath log [--session ID] [--profile NAME] [--denied] [--since 1h] [--json] [--follow]
```

Reads the [audit log](/guides/inside-a-session/#session-history).

## Answers

See [answering requests](/guides/approvals/).

### `doriath approvals`

```txt frame="none"
doriath approvals [list]
```

Lists the requests that wait in every running session.

### `doriath approvals allow`

```txt frame="none"
doriath approvals allow ID [--for once|session|DURATION]
```

Allows a request, once, for the session, or for a duration such as `30m`.

### `doriath approvals deny`

```txt frame="none"
doriath approvals deny ID [--reason TEXT]
```

Denies a request. The agent sees the reason.

### `doriath approvals grant`

```txt frame="none"
doriath approvals grant PATH [--session ID]
```

Makes a path writable in a running session, without a request from the agent.

### `doriath web`

```txt frame="none"
doriath web [--listen HOST:PORT]
```

Serves the [approvals page](/guides/approvals/#the-approvals-page). The home-manager service runs this command for you.

### `doriath web open`

```txt frame="none"
doriath web open [--listen HOST:PORT] [--print]
```

Opens the approvals page with a link that works one time. `--print` prints the link, for a browser on another machine. Over SSH, the command prints the link and the tunnel to make.

## Configuration

### `doriath profiles`

```txt frame="none"
doriath profiles [list | show NAME [--json] | edit NAME | allow NAME [--current DIR] | login NAME [SECRET] | clean NAME]
```

- `list` and `show` list the profiles and show one. `show` names the module behind each mount, host and rule, and `--json` prints the whole profile for scripts.
- `edit` opens a profile in your editor, and checks it when you save.
- `allow` allows a profile for sessions in the repository of `--current DIR`, or of the working folder, and shows what it gives. Use it where a session has no terminal to ask in. See [allowed profiles](/reference/configuration/#allowed-profiles).
- `login` signs in to the OAuth secrets of a profile. See [OAuth logins](/reference/configuration/#oauth-logins).
- `clean` removes the caches of a profile, when none of its sessions runs.

### `doriath modules`

```txt frame="none"
doriath modules [list | show NAME [--path]]
```

Lists the modules and their sources, or prints a module or the path to it. See [modules](/reference/modules/).

## Repositories

### `doriath restore`

```txt frame="none"
doriath restore SESSION [BRANCH...]
```

Puts back the branches and bookmarks that moved while a session ran, or only the ones that you name. Another program can move a branch during a session too, so check the list first. See [repositories](/reference/configuration/#repositories).

### `doriath clean`

```txt frame="none"
doriath clean
```

After you confirm, removes old backups and the agent worktrees that are already in the default branch.

## Setup

### `doriath doctor`

```txt frame="none"
doriath doctor [--secrets] [--profile NAME]
```

Checks the machine. `--secrets` also gets each secret one time, and can ask you to unlock a password manager. Before it runs the secret commands of a profile, it asks you as `run` does; see [allowed profiles](/reference/configuration/#allowed-profiles).

In a repository, doctor also checks it with the profile that its `.envrc` names in `use doriath PROFILE`, or with `--profile`, or with a profile named `default`. It tells whether the jail shows the repository, whether the agent can commit there, and whether the commits can be signed as your git or jj config asks.

### `doriath direnv`

```txt frame="none"
doriath direnv
```

Prints the [direnv](/guides/direnv/) library.

### `doriath completion`

```txt frame="none"
doriath completion zsh
```

Prints the zsh completion.

### `doriath version`

```txt frame="none"
doriath version
```

Prints the version.

## Inside a jail

### `doriath request write`

```txt frame="none"
doriath request write PATH [--reason TEXT]
```

Asks you to make a path writable.

### `doriath request edit`

```txt frame="none"
doriath request edit PATH [--reason TEXT] < NEW_CONTENT
```

Asks you to change a read-only file to the new content, and writes the change once. Changes that the profile marks as safe need no answer. See [edits](/reference/configuration/#edits).

### `doriath request wait`

```txt frame="none"
doriath request wait ID|HOST|PATH
```

Waits for the answer to a request.

doriath also runs some commands of its own inside the jail. Their names start with `__`, and you do not type them.
