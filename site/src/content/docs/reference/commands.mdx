title: Commands
description: Every doriath command, on the host and inside a jail.
---

Arguments in capitals are values that you give. Arguments in brackets are optional. A command for one session takes `--session ID`, which you need only when more than one session runs.

## Sessions

### `doriath run`

```txt frame="none"
doriath run --profile NAME [--current DIR] [--learn] -- COMMAND
```

Runs a command in a jail for the profile. `NAME` can join profiles with `+`, such as `my-app+repo:dev`, as [composed profiles](/reference/configuration/#composed-profiles) and [repository profiles](/reference/configuration/#repository-profiles) describe. `--current DIR` sets the folder of the session in place of the working folder.

`--learn` makes all public hosts reachable, and prints the hosts that the session used, as [install](/install/#find-the-hosts-of-a-build) describes. Before the first session of a profile, and when the profile gives more than you allowed, `run` asks you. See [allowed profiles](/reference/configuration/#allowed-profiles).

### `doriath exec`

```txt frame="none"
doriath exec [--session ID] [-- COMMAND]
```

Runs a command as a new process in a running jail. Without a command, it starts a shell. See [looking inside a session](/guides/inside-a-session/).

### `doriath forward`

```txt frame="none"
doriath forward [--session ID] PORT[:JAIL_PORT]
```

Makes a port of the jail reachable on the loopback address of the host, until you stop the command. The agent asks for the same forward with [`doriath request forward`](#doriath-request-forward).

### `doriath status`

```txt frame="none"
doriath status [--session ID]
```

Lists the running sessions. With one session, or with `--session`, it shows what the session allows and what it blocked. In the jail, the agent runs it to see its own session.

### `doriath log`

```txt frame="none"
doriath log [--session ID] [--profile NAME] [--denied] [--since 1h] [--json] [--follow]
```

Reads the [audit log](/guides/inside-a-session/#session-history).

## Answers

See [answering requests](/guides/approvals/).

### `doriath approvals`

```txt frame="none"
doriath approvals [list]
```

Lists the requests that wait in every running session.

### `doriath approvals allow`

```txt frame="none"
doriath approvals allow ID [--for once|session|DURATION]
```

Allows a request, once, for the session, or for a duration such as `30m`.

### `doriath approvals deny`

```txt frame="none"
doriath approvals deny ID [--reason TEXT]
```

Denies a request. The agent sees the reason.

### `doriath secrets provide`

```txt frame="none"
doriath secrets provide [--session ID] NAME
```

Gives a running session the value of one of its secrets, such as a token that its source did not give. The profile must name the secret. In a terminal, the command asks for the value without echo. Otherwise it reads the value from standard input, such as `rbw get my-token | doriath secrets provide acme`.

The session uses the value until it ends, and does not read the source again. This command cannot give the signing key or an OAuth login.

### `doriath web`

```txt frame="none"
doriath web [--listen HOST:PORT]
```

Serves the [approvals page](/guides/approvals/#the-approvals-page). The home-manager service runs this command for you.

### `doriath web open`

```txt frame="none"
doriath web open [--listen HOST:PORT] [--print]
```

Opens the approvals page with a link that works one time. `--print` prints the link for a browser on another machine. Over SSH, the command prints the link and the SSH tunnel for it.

## Configuration

### `doriath profiles`

```txt frame="none"
doriath profiles [list | show NAME [--json] | edit NAME | allow NAME [--current DIR] | login NAME [SECRET] | clean NAME]
```

- `list` and `show` list the profiles and show one. `show` names the module behind each mount, host and rule, and `--json` prints the whole profile for scripts.
- `edit` opens a profile in your editor, and checks it when you save.
- `allow` shows what a profile gives, and allows it for sessions in the repository of `--current DIR` or of the working folder. Use it for a session without a terminal. See [allowed profiles](/reference/configuration/#allowed-profiles).
- `login` signs in to the OAuth secrets of a profile. See [OAuth logins](/reference/configuration/#oauth-logins).
- `clean` removes the caches of a profile. No session of the profile can run at that time.

### `doriath modules`

```txt frame="none"
doriath modules [list | show NAME [--path]]
```

Lists the modules and their sources. `show` prints a module, and `--path` prints its path. See [modules](/reference/modules/).

## Repositories

### `doriath restore`

```txt frame="none"
doriath restore SESSION [BRANCH...]
```

Puts back the branches and bookmarks that moved during a session, or only the ones that you name. Another program can also move a branch during a session, so read the list first. See [repositories](/reference/configuration/#repositories).

### `doriath clean`

```txt frame="none"
doriath clean
```

Removes old backups, and the agent worktrees whose commits are in the default branch. It asks you first.

## Setup

### `doriath doctor`

```txt frame="none"
doriath doctor [--secrets] [--profile NAME]
```

Checks the machine. `--secrets` also reads each secret one time, and a password manager can ask you to unlock it. Before doctor runs the secret commands of a profile, it asks you as `run` does. See [allowed profiles](/reference/configuration/#allowed-profiles).

In a repository, doctor also checks the repository with a profile: the one in `--profile`, the one that `use doriath` names in `.envrc`, or a profile named `default`. It tells whether the jail shows the repository, whether the agent can commit there, and whether it can sign as your git or jj config asks.

### `doriath direnv`

```txt frame="none"
doriath direnv
```

Prints the [direnv](/guides/direnv/) library.

### `doriath guide`

```txt frame="none"
doriath guide profile | skill
```

`profile` prints the steps for an agent that writes a profile. `skill` prints a skill that points an agent to these steps. See [profiles with an agent](/guides/profile-setup/).

### `doriath completion`

```txt frame="none"
doriath completion zsh
```

Prints the zsh completion.

### `doriath version`

```txt frame="none"
doriath version
```

Prints the version.

## Inside a jail

### `doriath request write`

```txt frame="none"
doriath request write PATH [--reason TEXT]
```

Asks you to make a path writable until the session ends. The path can be a folder that the jail does not show, if the folder exists.

### `doriath request module`

```txt frame="none"
doriath request module MODULE PATH [--reason TEXT]
```

Asks you to use a module of the profile in another repository, until the session ends. PATH names the repository or a path in it. The module applies there as in a session that starts there: the agent gets the module's writable paths and its store, so it can commit with [`vcs-readwrite`](/reference/modules/#vcs-readwrite). The files that the profile keeps read-only, hidden or held stay so, from every module and from the profile. `doriath status` lists the modules that the agent can ask for.

doriath refuses the request when the profile hides a path with content in that repository, because it cannot hide a path in a running jail. Start a session in that repository instead.

### `doriath request open`

```txt frame="none"
doriath request open URL|PATH [--reason TEXT]
```

Asks to open a link in your browser, or a file with the app of your machine for it, as [links](/reference/configuration/#links) describes. In the jail, `xdg-open` and `$BROWSER` run this command. For a link to `localhost`, doriath first asks you to forward its port, as `doriath request forward` does.

### `doriath request forward`

```txt frame="none"
doriath request forward PORT[:JAIL_PORT] [--reason TEXT]
```

Asks you to connect a port on the loopback address of your machine to a port in the jail, until the session ends. Without `JAIL_PORT`, the two ports are the same. The agent uses it to show you a server that it runs, such as a preview of a site. See [ports](/guides/approvals/#ports).

### `doriath request host`

```txt frame="none"
doriath request host HOST [--reason TEXT]
```

Asks you to let the jail reach a host that the profile does not allow, until the session ends. The request shows the reason.

### `doriath request read`

```txt frame="none"
doriath request read PATH [--reason TEXT]
```

Asks you to show a folder that the jail does not show, read-only, until the session ends.

### `doriath request edit`

```txt frame="none"
doriath request edit PATH [--reason TEXT] < NEW_CONTENT
```

Asks you to change a read-only file to the new content. doriath writes the change once. A change that the profile marks as safe needs no answer. See [edits](/reference/configuration/#edits).

### `doriath request wait`

```txt frame="none"
doriath request wait ID|HOST|PATH
```

Waits for the answer to a request.

doriath also runs commands of its own in the jail. Their names start with `__`. Do not type them.
